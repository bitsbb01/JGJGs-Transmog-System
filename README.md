# JGJGs Transmog System

In development for Skyrim Steam 1.6.1170. No installable release yet.

Planned: standard SkyUI MCM controls, same-type weapon and compatible armour appearance overrides, cached catalogue of installed items, paginated search, saved appearance presets, and an original/selected appearance preview prototype. Original equipment statistics and enchantments must be preserved.

SKSE and SkyUI are the intended runtime requirements. No PrismaUI or MCM Helper UI dependency is planned. Additional runtime requirements, if necessary, will be documented before release.

The game patcher/debug-menu idea is a separate project.
