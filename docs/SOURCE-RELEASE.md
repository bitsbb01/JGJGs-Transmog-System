This is a SOURCE PREVIEW of JGJGs Transmog System, not an installable Skyrim mod.

It contains the tested catalogue/compatibility/preset-selection core, a read-only SKSE catalogue component, MCM source draft, and packaging/build automation.

Appearance rendering, game-save persistence, complete MCM integration, and side-by-side 3D preview remain unfinished. No playable release is claimed. No compatibility beyond Steam 1.6.1170 is claimed.

Download the SOURCE ZIP to inspect or develop the project. Checksums are included. Future playable packages will be clearly labelled for Mod Organizer 2, Vortex and manual installation.
