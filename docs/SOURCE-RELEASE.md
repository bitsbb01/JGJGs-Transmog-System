This is a SOURCE PREVIEW of JGJGs Transmog System, not an installable Skyrim mod.

It contains the catalogue/compatibility/preset-selection core, the player armor appearance prototype, MCM source, and packaging/build automation.

Weapon appearance rendering, favourite presets, and the side-by-side 3D preview remain unfinished. The armor and save/load work still requires in-game testing. No playable release is claimed. No compatibility beyond Steam 1.6.1170 is claimed.

Download the SOURCE ZIP to inspect or develop the project. Checksums are included. Future playable packages will be clearly labelled for Mod Organizer 2, Vortex and manual installation.
